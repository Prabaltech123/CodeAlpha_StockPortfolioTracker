
# Stock Portfolio Tracker - Python

## About the Project
The Stock Portfolio Tracker is a Python application developed as part of the CodeAlpha Python Programming Internship.

It helps users calculate the total investment value of their stock holdings using stock prices and quantities.

## Features
- Add stocks to the portfolio.
- Enter the quantity of each stock.
- Calculate the total investment value.
- Remove stocks from the portfolio.
- Save portfolio details to a CSV file.
- Simple graphical user interface.

## Technologies Used
- Python 3
- Tkinter
- CSV module

## Stock Prices
The application uses predefined example prices for stocks such as:
- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN

**Note:** These are example prices, not live market prices.

## Requirements
- Python 3 installed on your computer.
- VS Code or another Python editor.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   ```bash
   python stock_tracker.py
   ```

5. Enter the stock symbol and quantity.
6. Add stocks to calculate your total investment.

## How It Works
1. The user selects or enters a stock symbol.
2. The user enters the quantity of shares.
3. The application calculates the investment value using the predefined price.
4. The portfolio total is updated.
5. The user can save the portfolio to a CSV file.
